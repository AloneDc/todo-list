# To-Do List

Una aplicación simple de lista de tareas hecha con HTML, CSS y JavaScript.

## Características

- Agregar tareas.
- Eliminar tareas.
- Guardar tareas en el almacenamiento local (localStorage).

## Cómo Usar

1. Clona este repositorio.
2. Abre el archivo `index.html` en tu navegador.
3. ¡Empieza a agregar tareas!
